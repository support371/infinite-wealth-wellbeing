# Release 3 - Public Website Clarity Reset

This release separates the public website from the internal platform engine.

## Why

The previous visible website drifted into backend, DevOps, API and compliance engine language. Those details are useful for internal platform development, but they made the public website hard to understand.

## Public website rule

Visitors should quickly understand:

- what Infinite Wealth & Well-being is
- what the organization offers
- how to join
- how practitioners apply
- how to donate or contact the organization
- why the organization can be trusted

## What changed

- Removed Platform/Ops from primary public navigation.
- Removed API, database, webhook and DevOps language from visible pages.
- Reframed Trust as simple public governance and policy language.
- Kept backend and compliance engineering files in the repository for internal development.
- Restored a warmer, clearer organizational homepage.

## Internal engine rule

Technical platform work should stay in documentation, admin-only routes, backend services and developer workflows unless it directly helps a public visitor.
