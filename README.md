# Infinite Wealth & Well-being

Release 1 platform scaffold for a mission-led organizational website and governed operating system.

## What is included

- Public website architecture with routed page groups
- Membership, practitioner, resources, donation and trust center modules
- API/webhook readiness documentation
- Compliance record and trustee governance structure
- Media and video placeholder strategy
- DevOps hardening notes and environment placeholders

## Important security note

No secrets, API keys, tokens or private credentials are committed. Configure secrets only through protected hosting environment variables.

## Suggested next command

```bash
npm install
npm run dev
```
